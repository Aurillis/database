三色产品变更判断框架

🟢 绿色：一般可推进，仍需记录

  • 品牌名称
  • 型号名称
  • 包装视觉
  • 外壳颜色
  • 不影响性能的人机界面文字调整
  • 不改变安全性和有效性的轻微外观变化
绿色不代表无需审核，仍应纳入差异报告。

🟡 黄色：须由依士文和专业机构评估

  • 外壳结构；屏幕；按键；线材；接口
  • 电极探头尺寸；电极探头材料
  • 软件界面；训练记录功能；新增记忆功能
  • 包装结构；英文说明书
  • 警告语和禁忌症

🔴 红色：未经新法规评估不得修改

  • Intended Use 预期用途
  • Indications for Use 适用范围
  • 治疗原理；核心波形
  • 输出电流；输出电压；脉冲宽度；频率范围
  • 关键治疗模式；关键安全控制
  • 与510(k)清关内容不同的医疗宣称
贴牌、改品牌或新增型号不等于可以改变产品的医疗用途和核心技术参数。

5FDA注册、Device Listing、510(k)和UDI

Registration · Listing · 510(k) · UDI

FDA Establishment Registration

中文：FDA企业或场所注册

回答的问题：“哪些企业或场所参与了医疗器械生产、出口、进口或相关活动？”

  • 注册需要按年度维护
  • 注册不能证明产品获得 510(k)
  • 禁止 虚构 Registration Number 或 FEI Number

Device Listing

中文：医疗器械产品列名

回答的问题：“某个已注册企业正在生产或经营哪些医疗器械？”

本项目拟议安排：

  • 由依士文将 Aurillis 品牌和型号纳入正确的 Device Listing
  • 必须确认 Listing 所关联的 510(k)、产品代码、品牌和型号准确

510(k)

中文：上市前通知 / 实质等同路径

回答的问题：“该产品是否通过实质等同路径获得上市许可？”

  • 510(k) 不是企业注册
  • 510(k) 不是 Device Listing
  • 510(k) 不是品牌授权书
  • 使用工厂 K 号必须确认最终产品是否仍在其许可范围内

UDI

中文：唯一器械标识

回答的问题：“如何通过标准化编码识别具体医疗器械、版本和包装层级？”

本项目拟议安排：

  • 香港欧律生完成 FDA 注册后，计划自行承担 UDI Labeler 角色
  • 需选择符合 FDA 要求的 UDI Issuing Agency
  • 建立 DI、包装层级、标签和 GUDID 数据之间的对应关系
  • 具体流程 待专业机构确认
UPC 和 UDI 可能都使用 GS1 体系，但 UPC 商品条码不能简单等同于 UDI。

6Amazon医疗器械上架合规

Amazon Medical Device Listing Compliance

平台明确规则

运营需要准备或随时能够提供：

  • 产品真实名称
  • 品牌和型号
  • 510(k) Number
  • Manufacturer 信息
  • FDA Registration 相关信息
  • Device Listing 相关信息
  • 产品标签
  • 英文说明书
  • 包装图片
  • UDI 信息
  • 产品实拍图
  • 授权或合作关系文件
  • 适用的检测报告
  • 供应商及生产信息
  • 标签与说明书一致性
  • 包装与页面一致性
  • 合规文件可核验版本
  • 提交与回复记录
• Amazon 审核通过 ≠ FDA 已经确认合规。
• FDA 网站能查到 K 号，≠ Aurillis 产品自动获得覆盖。
• 产品图片、标签、说明书和 Amazon 页面宣称必须保持一致。
• 平台可能要求补充多个文件，不一定一次性告知全部要求。
• 禁止 把未经确认的医疗宣称写入标题、五点、A+、图片或广告。

项目操作原则

  • 上架前先建立完整合规资料包
  • 文件中的品牌、型号、公司名称和地址保持一致
  • PDF 文件使用清晰、完整、可核验版本
  • 不上传经过涂改、拼接或无法追溯的合规文件
  • 每次修改 Listing 前，先判断是否涉及医疗宣称
  • 禁止 运营单独修改 Intended Use、适用人群或治疗效果
  • 产品分类、FDA 信息和医疗宣称变化，先由项目负责人审核
  • 保存每次向 Amazon 提交的文件和平台回复记录

7Amazon运营实操避坑

Operational Pitfalls
常见做法风险正确处理方式
把 Amazon 审核通过当作 FDA 合规平台审核只是平台层面的准入判断，不能替代 FDA 合规责任。同时维护 FDA 证据链和 Amazon 资料链。
直接使用工厂 K 号上架若没有品牌、型号、Listing 和产品差异文件，易被质疑产品与 K 号关系。准备工厂授权、Device Listing、产品差异说明和标签资料。
运营自行扩大医疗宣称页面宣称可能超出 510(k) 许可范围，触发平台审核或 FDA 风险。建立“允许使用的宣称词库”和“禁止使用的宣称词库”。
为上架把 Class II 产品填成普通商品可能造成分类错误、文件不一致和账号风险。按照产品真实法规属性申报。
UPC、型号、UDI 和 ASIN 关系混乱可能影响上架审核、HSA/FSA、后续追溯和召回。建立一份统一的编码映射表。
先发货，再补 FDA 注册或 Device Listing可能造成 FDA 进口申报错误、扣货或无法解释主体关系。发货前完成注册、Listing 及 ACE 数据预审。
让货代自行决定 FDA Shipper 或 DFE货代可能按运输习惯填写，而非按 FDA 角色填写。由 FDA 顾问、美国报关行和项目负责人共同确认。
使用不披露 IOR 和 ACE 数据的包税渠道公司无法确认谁承担进口责任，也无法取得完整进口档案。必须知道 IOR、Customs Broker、ACE 申报数据和最终进口文件。
购买账号、伪造资料或借用无关资质高风险行为，可能造成账号、资金、库存和监管风险。只使用真实公司、真实产品和真实文件。
把行业“潜规则”当作正式政策个别卖家历史经验不一定适用当前平台规则，也不一定合规。将内容分为“官方规则 / 实操经验 / 风险做法”三个等级。

9运营允许使用与禁止使用的规则

Allowed vs. Prohibited for Operations

🟢 运营可以做

  • 使用已经审核通过的产品名称和医疗宣称
  • 按照统一资料包提交 Amazon 审核
  • 维护 UPC、UDI、型号和 ASIN 映射
  • 保存平台回复和提交记录
  • 发现竞品新宣称时提交内部评估
  • 收集客户反馈并转交质量和产品团队
  • 根据批准版本制作页面和广告

🔴 运营不能单独做

  • 修改产品预期用途
  • 增加新的疾病治疗宣称
  • 把医疗器械改成普通消费品分类
  • 修改 Manufacturer 信息
  • 随意填写 FDA Registration 或 Listing Number
  • 直接使用工厂 K 号但不核实产品覆盖
  • 修改型号后不通知供应链和合规负责人
  • 自行制作或修改 FDA 文件
  • 使用虚假授权、拼接文件或无关检测报告
  • 承诺 HSA/FSA 资格
  • 让货代代替公司决定 FDA 角色

11HSA/FSA

HSA / FSA Eligibility Path
HSA/FSA 是美国健康消费账户的支付资格路径，不是 FDA 许可。产品完成 FDA 合规并不代表自动获得 HSA/FSA 资格。

建议路径

  1. 确认产品是否属于可使用 HSA/FSA 支付的合格医疗费用
  2. 确认产品是否属于需要处方或 Letter of Medical Necessity 的类型
  3. 确认香港欧律生、美国销售结构和商品编码关系
  4. 准备 UPC、品牌、型号、产品类别和 FDA 支持文件
  5. 按照 SIGIS 及相关支付资格规则进行申请或数据提交
  6. 建立 UPC 与 Amazon ASIN 的准确映射
  7. 向 Amazon 提交 HSA/FSA 相关申请或配合平台数据匹配
  8. 检查商品详情页是否出现 FSA/HSA Eligible 标识
  9. 监控 UPC、ASIN、变体及包装调整是否影响资格

16专业名词库

Glossary

鼠标悬停页面内英文缩写也可显示中文解释。以下为完整术语对照：

Manufacturer
制造商
实际生产医疗器械的企业。
Foreign Manufacturer
境外制造商
位于美国以外的制造商。
Specification Developer
规格开发商
对最终设计规格和设计控制独立负责的主体，可能被认定为需注册方。
Foreign Private Label Distributor
境外自有品牌经销商
以自有品牌转售他人制造产品，位于境外。
Foreign Exporter
外国出口商
将产品出口至美国的相关主体，是 FDA 角色而非中国报关角色。
Establishment Registration
企业或场所注册
企业/场所向 FDA 登记其医疗器械相关活动。
Device Listing
医疗器械产品列名
已注册企业列明其生产或经营的医疗器械。
510(k)
上市前通知 / 实质等同路径
证明产品与已上市合法产品实质等同的上市路径。
K Number
510(k) 编号
如 K241899。
UDI
唯一器械标识
用于识别医疗器械的标准化编码。
UDI Labeler
UDI 标签责任方
负责将 UDI 赋予并标注于标签的主体。
DI
器械标识
UDI 中识别标签主体与包装层级的固定部分。
PI
生产标识
UDI 中识别批次、序列号、生产日期等的可变部分。
GUDID
全球唯一器械标识数据库
FDA 维护的 UDI 公开数据库。
U.S. Agent
美国代理人
FDA 与境外企业之间的美国联系窗口。
Importer of Record
美国海关进口申报责任主体
承担 CBP 进口申报责任的美国主体。
Device Initial Importer
医疗器械初始进口商
器械首次进入美国商业链条的进口责任主体。
Customs Broker
美国报关行
代理办理美国海关进口申报的机构。
ACE
美国自动化商业环境申报系统
CBP 用于进口申报的自动化系统。
DFE
FDA 境外出口方相关实体代码
FDA 申报中的 Foreign Exporter 实体标识。
DEV
FDA 境外制造商相关实体代码
FDA 申报中的 Manufacturer 实体标识。
LST
Device Listing 相关编号
与产品列名关联的标识。
PM#
上市前申报编号
如 510(k) 编号的申报标识。
Delivered-to Party
最终送达方
货物最终送达的地址/主体，如 FBA 仓库。
FDA May Proceed
FDA 允许货物继续进口流程
FDA 对进口器械放行或未异议的指令。
MDR
医疗器械报告
不良事件报告义务。
CAPA
纠正和预防措施
质量体系中的 corrective and preventive action。
Recall
召回
对已上市缺陷产品的收回/纠正措施。
HSA
健康储蓄账户
免税医疗储蓄账户。
FSA
灵活支出账户
税前灵活医疗支出账户。
SIGIS
特殊利益群体信息标准机构
管理 HSA/FSA 合格商品数据标准的组织。
UPC
通用商品代码
零售商品条码，不等于 UDI。
ASIN
Amazon 标准识别号
Amazon 平台商品唯一标识。
