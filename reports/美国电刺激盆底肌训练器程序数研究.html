产品定义：建议设置6个核心程序

建议原因：6个程序能够覆盖三类核心漏尿症状和三个关键训练阶段，形成完整但不过度复杂的使用路径。相比4个程序，它能进一步区分低强度入门、力量强化和耐力训练；相比9–10个以上程序，又能避免名称相近、选择困难和说明成本过高。成熟竞品的销售表现主要集中在5–8程序区间，但销量仅作为辅助证据，最终依据仍是症状覆盖、训练目标差异和用户理解成本。

用户如何看待程序数量与模式名称

证据来自10款代表性竞品的SellerSprite美国站全星级评论检索，以及Reddit、专业机构与官方文件的语义交叉验证。评论主题允许同一条反馈进入多个维度，不按单词机械分类。

用户结论：用户需要的不是“更多程序”，而是少做判断、不会选错、能够确认正在有效刺激。5–8个程序可以提供足够覆盖，但前提是名称直接对应症状或训练目标；当设备只显示P1–P10、功能和线材很多、说明书又无法快速解释差异时，程序数量会由卖点变成使用阻力。
5–8个

更合理的主程序区间

足以覆盖Stress、Urge、Mixed、基础强化、耐力和维持。评论没有显示用户会因为10个以上程序本身获得更强疗效感。

P1/P2

编号不能独立承担命名

Reddit用户会反复对照手册确认P1、P2是否适合混合型漏尿，并困惑程序时长、强度刻度与mA是否对应。

22 + 6

高功能量存在双向评价

K-fit Plus的22个刺激程序和6个游戏被部分用户认为功能丰富、价值高，也被另一部分用户评价为复杂、步骤多、难以开始。

症状名称

比波形名称更容易选择

Stress、Urge、Mixed等名称能建立使用入口；“Long wave / Short wave / Alternating”可作为次级说明，不应成为新手主菜单。

用户对“程序数量”的真实看法

  1. 数量适中是加分：不同模式与强度让用户能按舒适度和恢复阶段调整，但评论通常赞扬的是“可定制”，并非数量本身。
  2. 过多选择会降低启动率：复杂线材、附件、长说明书和大量功能叠加后，用户会觉得麻烦，甚至未开始使用便放弃。
  3. 专用性胜过通用性：有用户明确偏好只针对Kegel/盆底问题的设备，认为其他模式反而干扰核心任务。
  4. 效果确认比再加模式重要：“没有感觉”“提高档位仍不确定”“程序结束不明显”等反馈说明，接触状态、有效收缩和剩余时间反馈更关键。
  5. 不同程序必须产生可解释差异：若用户无法理解频率、工作/休息节律和适用症状的差异，10个编号程序在感知上仍接近一个程序。
模式名称评价
  • 最清楚：“压力型漏尿 / 急迫型漏尿 / 混合型漏尿”加生活场景说明。
  • 可以保留：“基础唤醒 / 强化 / 耐力 / 维持”，但要解释训练目标与适用阶段。
  • 需要谨慎：“产后恢复”不能默认适合所有产后用户，应附开始条件和禁忌提示。
  • 不宜作为主名称：P1–P10、M1–M10、Long Wave、Burst、Massage等编号或波形词。
  • 高风险混淆：Relax / Pain与Strength并列却不解释。用户可能把高张、疼痛或无法放松误当作肌无力继续强化。

建议的显示命名：症状入口 + 训练目标 + 专业参数

主屏只让用户完成一次低认知负担的选择；编号和波形参数放到详情层，而不是让用户先学会电刺激术语。

不能混在一起比较的“模式”

3-in-1

EMS + 红光 + 震动

这是三种功能模块，不等于三个EMS治疗程序。

36

通用TENS/EMS模式

多用于身体疼痛与肌肉刺激，只有少部分适合盆底探头，不能直接宣称36个盆底程序。

50档

强度档位

代表刺激幅度调节精细度，不代表治疗逻辑数量。

自定义

频率/脉宽/工作休息

是专业参数能力，应放在高级层，不宜替代新手可理解的预设程序。

首发产品建议：6个核心程序 + 1个引导程序

不建议为了参数竞争直接做10个名称相近的模式。首发应先让用户理解“我该选哪个、是否接触正确、训练是否有效”。

  1. Stress：咳嗽、跳跃、运动时漏尿，强调有效肌肉收缩。
  2. Urge：突发尿意、来不及到厕所，采用较低频连续刺激逻辑。
  3. Mixed：Stress与Urge组合，分阶段运行。
  4. Tone / Recovery：基础强化、产后恢复与疗程后的维持训练。
  5. Fit Test：短时接触测试和刺激体验，不计为治疗程序。
比“增加程序数”更优先
  • 探头接触 / 开路检测
  • 首次使用低强度渐进引导
  • 每个程序明确适用症状和禁忌
  • 显示工作、休息、剩余时间和刺激状态
  • 记录训练完成率与阶段进展
  • 把专业参数放入Pro层或隐藏设置

产品路线：基础款6+1；精简款4+1；专业生物反馈款再扩展到12-22及自定义。
