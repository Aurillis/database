竞争情报要点

同一企业两条产品线K252601 = 电刺激+压力生物反馈一体机 (对标 Yarlap II); K252748 = 纯APP游戏化盆底训练器 (对标 Perifit Care+)
可充气阴道探头K252601 采用内置电动气泵驱动的可充气硅胶探头 (0~100mmHg)，对标 ApexMV 的手动气泵方案 — 电动充气是技术升级点，提升了用户操作便利性
技术路线分化K252601 走传统有源电刺激路线 (KPI产品代码, GU委员会); K252748 走新兴无源力敏传感路线 (HIR产品代码, OB委员会)
主对比器械 K160773 含 HCCYarlap II 同时注册了 KPI + HCC 双产品代码，与审计报告发现的 HCC 遗漏形成交叉验证
审查委员会差异KPI 记录的 advisory_committee = GU; HIR 记录的 advisory_committee = OB — 印证了之前发现的 HIR 审查委员会标注问题
申报顾问Chonconn Consulting (深圳) — 可能是专门的FDA注册代理机构
全部8个K号在库包括申报设备2条 + 直接对比器械3条 + 间接对比器械2条 + 初代产品1条，均在现有数据库(177条)中。全部对比器械的510(k) Summary PDF均可公开访问，数据经 openFDA API 交叉验证
