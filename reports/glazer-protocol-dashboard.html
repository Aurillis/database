Glazer Protocol：从盆底肌电评估到欧律生二代产品闭环

不是给盆底肌打一个游戏分，而是看清它究竟哪里需要改善。

Glazer Protocol 不是一张测完就能诊断疾病的国际统一评分表，而是一套相对标准化的盆底表面肌电测试流程。

欧律生真正需要建立的是：
标准化评估 → 识别主要功能短板 → 匹配训练方案 → 阶段性复测 → 判断具体改善了什么。

先保证数据有效，再解释结果；先识别功能短板，再推荐训练。

1

Glazer 是什么

先分清三件事：一套测试流程、一种采集技术、以及它和临床诊断的关系。三者不能混为一谈。
协议 / PROTOCOL

Glazer Protocol

一套规定「什么时候放松、什么时候收缩、持续多久、采集哪些参数」的标准化盆底表面肌电评估流程。它给出的是测量方法，而不是一张自带诊断结论的评分表。

技术 / sEMG

Surface EMG（sEMG）

Surface Electromyography，表面肌电。通过阴道表面电极记录盆底肌激活时产生的电信号，反映肌肉的募集数量、放电频率与激活时序。

临床 / DIAGNOSIS

临床诊断

需要结合症状、病史、体格检查以及其他专业检查。Glazer 与 sEMG 只能提供盆底肌功能信息，不能单独替代临床诊断。

sEMG 测量的是肌肉电活动，不直接等于真实肌力、阴道压力或疾病严重程度。
历史背景：1999 年，Howard I. Glazer、L. Romanzi 与 M. Polaneczky 在 The Journal of Reproductive Medicine 发表盆底表面肌电的可靠性及临床预测效度研究（57 名 19–69 岁女性），认为盆底 sEMG 可作为功能评估和生物反馈训练工具之一。该研究证明其具有良好的重测可靠性（P<.001）与对尿失禁等临床状态的预测效度（P<.05）。
2

它到底测量什么

把抽象的「肌力」拆成五个可观察的能力问题。这五个问题，正好对应后面五阶段测试。
问题 01
放松时，盆底肌能不能真正安静下来？
对应：静息基线 / 高张力识别
问题 02
需要快速收缩时，能不能迅速启动？
对应：快速收缩 / 启动速度
问题 03
需要持续用力时，能不能稳定保持？
对应：持续收缩 / 维持稳定
问题 04
长时间用力时，会不会很快疲劳？
对应：耐力收缩 / 衰减斜率
问题 05
训练完成后，能不能重新放松？
对应：后静息 / 放松质量
它不是只测「夹得多强」，而是同时观察收缩与放松、启动与维持、表现与恢复。
3

五阶段测试流程

一条连续的标准化流程：前静息 → 快速收缩 → 持续收缩 → 耐力收缩 → 后静息。每一段回答模块二里的一个问题。
1
STAGE 1 · 训练前静息 / PRE-BASELINE REST
放松能力
动作：完全放松
时间：60 秒
观察：平均肌电振幅、信号波动、基线稳定性
数据形态：低平、平稳的基线
通俗解释：不工作时，盆底肌能不能安静下来？
2
STAGE 2 · 快速收缩 / PHASIC CONTRACTION
快速启动
动作：快速收缩 2 秒，然后放松 2 秒
次数：5 次
观察：峰值、启动速度、放松速度、重复一致性
数据形态：5 个尖锐脉冲，高度与间隔应较一致
通俗解释：需要马上夹紧时，能不能迅速启动并迅速松开？
3
STAGE 3 · 持续收缩 / TONIC CONTRACTION
持续保持
动作：持续收缩 10 秒，然后放松 10 秒
次数：5 次
观察：平均激活水平、维持稳定性、后几次是否下降
数据形态：5 段较平稳的高位平台
通俗解释：需要持续用力时，能不能稳定保持？
4
STAGE 4 · 耐力收缩 / ENDURANCE CONTRACTION
耐力
动作：单次长时等长收缩（如持续至疲劳）
时间：通常 30–60 秒量级
观察：耐力收缩均值、下降斜率、疲劳出现时点
数据形态：高位平台随时间缓慢衰减
通俗解释：长时间保持时，会不会很快掉力？
5
STAGE 5 · 后静息 / POST-BASELINE REST
恢复
动作：完全放松
时间：60 秒
观察：平均肌电振幅、是否回落到前静息水平、放松时间
数据形态：应回到与前静息相近的低位
通俗解释：训练完成后，能不能重新放松？
说明：各阶段具体时长与重复次数在不同设备、研究与临床机构间存在细微差异；上表为常见方案示例。欧律生二代产品定义时应先固定一套自己的标准协议，再谈参考值。

关键参数

标准化评估采集的不只是一个数字，而是一组可解释的参数。下表把参数、含义与反映的肌肉能力对应起来。
参数含义反映的肌肉能力主要观察阶段
平均肌电振幅
μV		某段信号的平均电信号强度整体激活水平各阶段
静息基线振幅
μV		完全放松时的平均振幅静息张力是否过高（能否放松）前 / 后静息
快速收缩峰值
μV		每次快速收缩达到的最高振幅快肌（Ⅱ型纤维）反应能力快速收缩
持续收缩均值
μV		5 次 10 秒收缩的平均振幅慢肌（Ⅰ型纤维）募集与稳定持续收缩
耐力收缩均值
μV		长时等长收缩的平均振幅持续收缩 / 抗疲劳能力耐力收缩
变异系数
CV		信号波动程度（标准差 / 均值）收缩的稳定性、一致性持续 / 耐力
启动 / 上升时间
ms		从放松到峰值所需时间反应速度（能否迅速启动）快速收缩
放松 / 下降时间
ms		从峰值回到基线所需时间放松质量（能否迅速松开）快速 / 后静息
重复一致性多次收缩间峰值的接近程度动作控制的可重复性快速 / 持续

6

如何解释

解释顺序很重要：先验证数据有效，再对比参考值，最后识别短板、分型并匹配方案。切忌「拿到数就下结论」。
步骤做什么常见陷阱
1 · 数据有效性检查信号质量、基线稳定、是否有伪差（如腹压、体位、电极接触不良）把伪差当成真实肌电，导致误判
2 · 分相段对比把五个阶段分别对照参考区间，而非只看一个总分用一个「总分」掩盖某一阶段的明显短板
3 · 识别短板定位偏离最大的阶段（放松 / 启动 / 维持 / 耐力 / 恢复）平均化后看不出结构问题
4 · 功能分型区分高张力型、低张力型、混合型，或单一能力弱把所有人都套同一套训练
5 · 匹配方案针对短板给训练（放松训练 / 快肌 / 慢肌 / 耐力 / 生物反馈）方案与短板不匹配
6 · 阶段性复测同一协议、同一设备复测，看差值与画像位移单次测量即下定论
典型模式举例：前静息明显偏高 → 高张力 / 放松困难；后静息未回落到前静息水平 → 放松质量差；快速收缩峰值低且不一致 → 启动能力差。但这些只是「方向提示」，需结合分型与复测确认。
7

不能诊断什么

边界比能力更重要。清楚 Glazer / sEMG 不能替代什么，才能避免产品与合规风险。
边界 01

不能单独诊断疾病

不能单独诊断尿失禁、器官脱垂、盆底痛、性功能障碍等疾病。它提供的是功能层面的线索。

边界 02

不等于真实肌力 / 压力

sEMG 是电活动，不等于真实肌力、阴道压力或收缩力量。与 不是同一指标。

边界 03

不等同于手法分级

不能替代 Oxford 手法肌力分级，也不能替代医生的病史采集、体格检查与其他专业检查。

边界 04

参考值有人群局限

已发表参考值多来自特定人群，跨人群、跨设备直接套用会产生误导。

边界 05

单次测量不能定论

单次结果受状态、操作、伪差影响，需结合复测与趋势判断。

边界 06

不能替代医生判断

任何产品输出都应是辅助信息，最终诊断与处置应由具备资质的医疗人员做出。

8

产品化路径

欧律生二代盆底康复产品的内核，不是「再做一个评分游戏」，而是把 Glazer 范式闭环成可家用、可追踪的产品。
STEP 1
标准化评估
家用 sEMG 采集设备 + App 引导，跑通固定五阶段协议
→
STEP 2
识别功能短板
五阶段分相段分析 + 用户功能画像，定位偏离最大的阶段
→
STEP 3
匹配训练方案
针对短板给个性化 Kegel / 生物反馈 / 可选 EMS
→
STEP 4
阶段性复测
同一协议、同一设备复测，追踪趋势与差值
→
STEP 5
判断改善
看具体改善了什么（哪个阶段、多少 μV、画像位移）
闭环回到 STEP 1
复测结果重新进入评估 → 短板识别 → 方案调整，形成「评估—训练—复测—再评估」的持续闭环。这正是欧律生二代相对单次评分产品的核心差异。
产品定位一句话：用标准化 sEMG 评估把「哪里需要改善」说清楚，用闭环复测把「改善了多少」证明出来。

用户功能画像

把五阶段能力抽象为五维画像，便于产品经理、研发与运营统一语言，也便于向用户与医生解释。
健康参考（示意） 示例用户 · 混合型（示意）
  • 高张力型 放松弱
    前 / 后静息偏高，放松困难。训练重点应是放松与下行控制，而非一味「加紧」。
  • 低张力型 整体弱
    各阶段振幅普遍偏低，收缩力量不足。训练重点是逐步提升募集与维持。
  • 快速启动弱 启动差
    快速收缩峰值低、上升慢。对应快肌（Ⅱ型纤维）训练。
  • 耐力不足 易疲劳
    持续 / 耐力段衰减快。对应慢肌（Ⅰ型纤维）与抗疲劳训练。
  • 混合型 组合短板
    同时出现两类以上短板（如放松差 + 耐力不足），需组合方案与分阶段优先级。

10

与 Perifit 的区别

Perifit 是消费级「训练工具」的代表，Glazer 是「评估流程」的代表。二者不在同一层面，应互补而非直接替代。
维度Glazer / sEMG（评估范式）Perifit（消费级产品代表）
传感原理表面肌电 sEMG（采集肌肉电信号）阴道压力传感 perineometry（采集收缩产生的阴道内压力）
测量对象肌肉电活动、激活与放松模式阴道内压力 / 力量曲线
是否标准化五阶段是 固定 Glazer 五阶段协议否 以游戏化训练为主，无统一评估协议
主要输出分相段参数 + 可解释评估报告游戏得分 / 力量曲线 / 训练进度
强项识别收缩 / 放松、启动 / 维持、疲劳的结构模式训练依从性高、趣味化、上手快
局限需专业解读、易受伪差影响不直接反映电活动，评估维度有限
与欧律生的关系二代产品的评估内核可借鉴其依从性 / 游戏化设计，用于训练层
结论：欧律生应把 sEMG + Glazer 范式 作为评估底座，同时向 Perifit 学习「让用户愿意坚持训练」的产品体验。评估做深、训练做轻，是更稳的产品定义。
11

产品开发优先级

按「数据有效是前提、闭环是差异化」的原则排序。P0 不做扎实，后面都是空中楼阁。
优先级模块说明 / 判断标准
P0家用 sEMG 采集有效性信号质量、伪差抑制、体位与电极接触引导。数据无效，一切解释归零。
P0五阶段分相段参数引擎 + 参考值体系核心算法：跑通固定协议、计算各阶段参数、建立自有参考区间。
P1用户功能画像 + 短板识别把参数翻译成「哪类用户、哪段短板」，是欧律生相对评分产品的差异点。
P1个性化训练方案匹配闭环关键：评估→方案→训练。方案与短板必须对应。
P2阶段性复测趋势追踪留存与证据：同一协议复测，呈现差值与画像位移。
P2报告可解释性（用户版 / 医生版）给用户看「改善了多少」，给医生看「结构化参数」，建立信任。
P3游戏化 / 社区（借鉴 Perifit）提升依从性，但属于体验层，不决定产品是否成立。
P3与 EMS / 物理反馈整合硬件扩张方向，待评估内核验证后再考虑。
排序逻辑：先做「测得准」（P0），再做「说得清、练得对」（P1），然后做「看得见进步、信得过」（P2），最后做「愿意坚持、能扩展」（P3）。
12

核心结论与资料来源

把首屏三句话收束为一页结论，并列出可追溯的资料来源。

1 · Glazer Protocol 不是一张测完就能诊断疾病的国际统一评分表，而是一套相对标准化的盆底表面肌电测试流程。

2 · 欧律生真正需要建立的是：标准化评估 → 识别主要功能短板 → 匹配训练方案 → 阶段性复测 → 判断具体改善了什么。

3 · 先保证数据有效，再解释结果；先识别功能短板，再推荐训练。
