Section 08

商业模式对比

同样卖盆底康复，四家赚钱的链路完全不同。

麦澜德

医院 → 科室 → 设备 → 耗材 → 女性健康解决方案

经销为主（2025 经销收入 3.50 亿元）、直销为辅（6,958 万元），覆盖三级 1,500+ / 二级及一级 5,000+ 机构；设备带动耗材及配件（1.22 亿元）复购；再用专科解决方案提升客单。

特点：专业深度高。

伟思

技术平台 → 多产品 → 多科室 → 医院渠道

同一磁刺激 / 电生理底层技术，横向覆盖精神、盆底、神经、医美、泌尿多个科室与产品线（2025 磁刺激 1.89 亿为第一大品类），国内 6,000+ 机构经销 + 直销。

特点：底层技术复用能力强。

拾光

产品 → 电商 / DTC → 家庭用户 → APP → 长期训练

硬件买断（淘宝 ¥3,499 标价）+ 京东自营 + 抖音直播 + 小红书种草；APP 承接评估 / 治疗 / 健康档案，持证康复师一对一在线指导与拾光学院内容服务。

特点：离消费者最近。

理邦

医疗设备 → 全球经销商 / 医院 → 多科室 → 全球注册 → 数据系统

六大业务板块共用全球渠道与注册体系，销往 170+ 国家、近 60,000 家医疗机构；海外收入占比 62.69%；盆底设备通过 PA4 Plus 对接信息管理系统沉淀数据。

特点：全球医疗商业基础设施最完整。

Section 12

Aurillis 观察

1 医院盆底治疗正在升级

医院盆底治疗正从单纯电刺激，向 评估 + EMG + 生物反馈 + 个性化治疗 升级——理邦 P/PA/PR 的多通道 + 智能报告 + >100 种方案、麦澜德 PI-ONE 的磁电热影融合 AI，都是这一方向的系统级落地。

2 技术成熟，家用体验仍有提升空间

中国专业医疗企业已具备成熟的 EMG / 压力检测 / EMS / ETS / 磁刺激 / 临床软件，但真正面向家庭消费者的产品体验仍有明显提升空间——拾光的产品与服务化探索说明「技术有了，体验还差一层」。

3 竞争关键不是「有没有 EMS」

未来家用盆底产品的竞争关键可能不是「有没有 EMS」，而是能否知道用户当前处于什么状态、下一步怎么训练——即 评估 → 治疗 → 反馈 → 调整 → 长期数据 的闭环能力。

4 三代产品路线

第一代：EMS/TENS + 程序化训练 + 家庭使用；第二代：EMG + APP + 生物反馈 + 评估 + 数据记录；第三代：评估 + 治疗 + 个性化方案 + 长期数据 + 专业人员连接。

只讲技术演进逻辑，不声称治疗无 FDA 适应症支持的疾病。
